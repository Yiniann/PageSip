# PageSip

一页一页，慢慢品读。

PageSip 是一款面向日语、英语原文小说的 AI 阅读器。导入自己的书籍，点击字词或选择句子，通过底部抽屉查看结合上下文的中文释义、读音与语法解释。

## 项目状态

项目已立项，目前处于规划阶段，尚未搭建可运行应用。

需求、建议架构、开发里程碑及待定事项见 [项目规划](docs/PLAN.md)。

## 已确定的方向

- 产品名：PageSip（Page + Sip，品读书页）。
- 支持日语、英语小说，由用户导入文章或书籍。
- 适配电脑网页、手机和平板。
- 点击字词，打开底部抽屉，使用 AI 结合上下文解释，不依赖词典。
- 使用 React 前端及 Tauri 应用封装；Node.js 作为建议的 AI 服务层。
- 后续支持段评。

## 建议的首版范围

本地书架、TXT/文字型 EPUB 导入、滚动阅读、目录与阅读进度、日英 AI 上下文解释、词句收藏。

先验证点击定位、AI 选词和解释体验，再实现完整阅读闭环。
